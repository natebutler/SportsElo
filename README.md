# 🏆 Sports Elo Ratings Hub

A unified, modern sports analytics dashboard tracking dynamic Elo ratings for **Major League Baseball (MLB)** and the **National Football League (NFL)**, deployed directly to **GitHub Pages**.

Built with a zero-build static architecture using **Tailwind CSS** and **Alpine.js**, backed by automated **R** data pipelines utilizing `mlbplotR` and `nflreadr`.

---

## ⚡ Features

- **Instant Tab Switching**: Flip between **⚾ MLB** and **🏈 NFL** with zero latency or page reloads.
- **100% Team Logo Preservation**: Direct integration with high-resolution ESPN CDN logos, official team branding colors, and scoreboard logos.
- **Interactive Leaderboard**:
  - Live search/filtering by team name or city abbreviation.
  - Column sorting for Rank, Team, Record, Daily Elo Change, and Elo Rating.
  - Medal badges for the top 3 contenders.
- **Season Elo Progression**: Embedded high-resolution trajectory chart generated by `mlbplotR` showing every team's path from opening day to today.
- **Automated Data Pipelines**: Scheduled GitHub Actions workflows that compute ratings, update JSON data, and refresh the live site.
- **Future Extensibility**: Modular JSON architecture designed to easily plug in NHL or other sports in the future.

## 📂 Repository Structure

```
SportsElo/
├── index.html                   # Unified modern dashboard (Tailwind CSS + Alpine.js)
├── data/
│   ├── mlb.json                 # Current MLB rankings, records, and logo links
│   ├── nfl.json                 # Current NFL rankings, records, and logo links
│   ├── mlb_trend.png            # MLB season trajectory graphic with scoreboard logos
│   ├── mlb_elo.rds              # R data backup for MLB
│   └── nfl_elo.rds              # R data backup for NFL
├── scripts/
│   ├── update_mlb.R             # Fetches MLB scores & computes Elo ratings
│   ├── update_nfl.R             # Fetches NFL schedules & computes Elo ratings
│   └── export_from_rds.R        # Helper to export JSON from local RDS files
├── .github/
│   └── workflows/
│       ├── update-mlb.yml       # Daily scheduled run (5:00 AM CDT)
│       ├── update-nfl.yml       # Weekly scheduled run (Tuesdays 10:00 AM CDT)
│       └── manual-update.yml    # On-demand manual trigger via GitHub Actions
├── MLBElo/                      # (Preserved) original MLB Elo repository
└── NFLElo/                      # (Preserved) original NFL Elo repository
```

## 🚀 Setting Up on GitHub Pages

1. Push this repository to your GitHub account (e.g., `https://github.com/your-username/SportsElo`).
2. In your repository on GitHub, navigate to **Settings** → **Pages**.
3. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main` (or `master`) and folder `/ (root)`.
   - Click **Save**.
4. GitHub Pages will build your site in seconds at `https://your-username.github.io/SportsElo/`.

---

## ⚙️ Automated Workflows

- **Daily MLB Update (`update-mlb.yml`)**: Runs every morning at 5:00 AM CDT during the baseball season, calculating daily game results and committing fresh `data/mlb.json` and `data/mlb_trend.png`.
- **Weekly NFL Update (`update-nfl.yml`)**: Runs every Tuesday at 10:00 AM CDT following Monday Night Football, computing week-by-week Elo ratings.
- **Manual Trigger (`manual-update.yml`)**: Allows manual execution anytime via the GitHub Actions UI.

---

## 🏒 Adding NHL in the Future

When you are ready to add the NHL:
1. Create `scripts/update_nhl.R` to compute NHL ratings and save `data/nhl.json`.
2. Add an `NHL` tab button in `index.html` (matching the MLB/NFL structure).
3. Add a scheduled workflow in `.github/workflows/update-nhl.yml`.
